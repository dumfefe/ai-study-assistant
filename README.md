
# AI Study Assistant

## Overview

The AI Study Assistant is a simple AI-powered application built using Python and the Hugging Face Transformers library.

The application uses the FLAN-T5-small pretrained model to generate simple responses to user questions.

## Features

- Accepts questions from the user
- Generates AI-powered responses
- Provides beginner-friendly explanations
- Allows multiple questions in one session
- Uses a pretrained AI language model

## Technologies Used

- Python
- Hugging Face Transformers
- FLAN-T5-small
- PyTorch

## How to Run

1. Install the required packages:

   pip install -r requirements.txt

2. Run the application:

   python app.py

3. Enter a question when prompted.

4. Type `exit` to close the application.

## Project Purpose

This project was created as part of an AI & ML internship to explore how AI tools and pretrained models can be used to build a simple educational application.
